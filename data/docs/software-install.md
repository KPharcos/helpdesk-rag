# Installing Software

Company laptops are managed centrally. You can install approved software yourself from the Company Portal; other software needs a request and a security review.

## Installing approved software

1. Open the "Company Portal" app (Windows) or "Self Service" app (Mac).
2. Search for the application, for example Zoom, Visual Studio Code, Python, 7-Zip or Adobe Acrobat Reader.
3. Click Install. The installation runs in the background and does not need administrator rights.

Most installations finish within 15 minutes. If an installation stays "pending" for more than an hour, restart the laptop while connected to the office network or the VPN.

## Requesting software that is not in the portal

1. Open the IT Service Portal at https://itportal.brightfield.example and choose "Request software".
2. Provide the software name, the vendor's website, the business reason and whether it is free or paid.
3. The security team reviews the request, typically within 5 working days. Paid software also needs approval from your manager and a cost centre.

Software that processes customer or employee data needs a data protection review, which can take up to 15 working days.

## Administrator rights

Standard users do not have local administrator rights. Developers can request temporary administrator access for 4 hours through the Company Portal item "Admin on demand"; each use is logged.

## Software that is not allowed

Do not install pirated software, browser extensions that are not on the approved list, personal cloud storage clients (for example personal Dropbox), remote-control tools such as TeamViewer, or cryptocurrency software. Such software is removed automatically and repeated attempts are reported to your manager.

## Licences

Paid licences are assigned to a person. When you no longer need a paid application, uninstall it via the Company Portal so the licence can be reused.
